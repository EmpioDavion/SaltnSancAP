# Salt and Sanctuary Setup Guide
## Installation
### Game
Go through the standard installation process for Salt and Sanctuary.

### Install Archipelago Mod
Download the Archipelago mod zip from the GitHub page:

[Archipelago Mod Download](https://github.com/EmpioDavion/SaltnSancAPClient/releases/latest)

Extract the zip to your Salt and Sanctuary directory.

An apworld file is also available for creating a yaml file through the Archipelago Launcher.

### Running the Game
Run BepInEx.NET.Framework.Launcher.exe in the Salt and Sanctuary directory.

### Configure Archipelago Mod
After creating a character, open your inventory and go to the Options menu.
In the Options menu, select AP Settings, you will see the settings for *Server*,
*Port*, *Slot*, and *Password* where you can fill in the relevant information.

The connection status will be shown in the AP Settings menu, and will also be
shown as a pickup notification.

AP Settings are per character, so loading other characters will not affect the Archipelago.

## Configuring Your YAML File
### What is a YAML and why do I need one?
You can see the [basic multiworld setup guide](/tutorial/Archipelago/setup/en) here on the Archipelago website to learn
about why Archipelago uses YAML files and what they're for.

### Where do I get a YAML?
You can use the [game options page for Salt and Sanctuary](/games/Salt_and_Sanctuary/player-options) here
on the Archipelago website to generate a YAML using a graphical interface.

## Visual Tracker
The Salt and Sanctuary Archipelago mod contains a built-in map system for tracking checks.

You can toggle the map by pressing M on your keyboard. This button can be rebound in the Options menu. 
The map can be zoomed using the Page Up and Page Down keys or the + and - keys on the numpad.
